Public hosting

Campaign Platform admin stays separate. This config points every local account at the organisation's voter-facing Cloudflare Pages host.

Cloudflare Pages

Public metadata only. API tokens and Turnstile secrets stay in Cloudflare environment secrets, never in Supabase.

Deploy target

Deploy only the public-host/ folder to the Cloudflare Pages project. Do not deploy the admin workspace there.

Secrets required in CloudflareSUPABASE_URL, SUPABASE_PUBLISHABLE_KEY, TURNSTILE_SECRET_KEY and — for domain automation — CLOUDFLARE_ACCOUNT_ID, CLOUDFLARE_PAGES_PROJECT and CLOUDFLARE_API_TOKEN.
